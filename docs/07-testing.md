# 07 测试与质量

[返回首页](../README.md)

测试以业务风险和行为为目标，不以单纯覆盖率代替正确性。开发者负责实现层测试，测试负责人组织跨模块与验收测试，业务负责人确认业务结果。

## 强制规则

| 编号 | 适用 | 执行要求 | 检查与证据 | 责任 |
| --- | --- | --- | --- | --- |
| TEST-001 | 需求交付 | 验收条件对应测试用例，覆盖正常、异常、边界和权限；变更影响范围有回归计划 | 需求到用例映射 | 测试负责人 |
| TEST-002 | 关键业务和授权 | 关键规则、金额、状态转换、权限、幂等与并发必须有自动化测试；缺陷修复补充有效回归用例 | 测试结果、评审 | 开发者 |
| TEST-003 | 持久化与外部依赖 | 用实际选定数据库或等价受控环境验证约束、事务和迁移；契约验证 HTTP、错误码及数据表示 | 集成与契约报告 | 开发负责人 |
| TEST-004 | 前端交付 | 验证组件交互、表单、加载与异常、竞态、权限展示和支持浏览器；关键业务流程有端到端验收 | 前端与端到端报告 | 前端负责人 |
| TEST-005 | 测试数据与环境 | 数据可重复、隔离且脱敏；时间、随机数和外部依赖可控制；禁止自动化测试写生产业务数据 | 环境清单、数据准备方案 | 测试负责人 |
| TEST-006 | CI 和发布 | 构建、必需测试及强制规则检查失败必须阻断；测试隔离或跳过有记录、期限和替代验证 | 流水线日志、例外 | 技术负责人 |
| TEST-007 | 覆盖率基线 | 登记项目阈值、统计范围、排除理由和执行方式；新增业务代码达采用的门槛，关键场景不能因覆盖率已达标而省略 | 覆盖率报告、场景清单 | 技术负责人 |
| TEST-008 | 性能与安全风险 | 按基线测试性能、容量、安全与依赖故障；给出环境、数据量、负载、采样区间及结论 | 性能与安全报告 | 测试负责人 |
| TEST-009 | 验收与缺陷 | 缺陷有严重度、复现、责任人和状态；已知问题明确业务影响、处置和验收结论 | 测试报告、缺陷清单 | 测试负责人 |

## 测试层次和建议门槛

| 层次 | 核心目标 | 常见场景 |
| --- | --- | --- |
| 单元 | 独立业务规则和边界 | 金额、状态机、校验、错误转换 |
| 组件 | Vue 组件与响应式行为 | props／events、表单、请求竞态、键盘交互 |
| 集成 | 真实技术边界 | 数据库约束、事务、幂等持久化、迁移、缓存故障 |
| 契约 | 前后端对接口理解一致 | HTTP 状态、响应包装、字符串 ID／金额、错误、分页 |
| 端到端 | 关键用户旅程 | 登录、创建、列表与详情、失败恢复 |
| 专项 | 业务风险与可运行性 | 性能、越权、依赖失效、恢复与回滚 |

推荐新增业务代码行覆盖率 ≥ 80%、分支覆盖率 ≥ 70%，前后端分别统计。默认新增范围为相对于合并目标分支的业务代码变更；若工具不能可靠统计增量分支，登记按受影响业务模块统计的替代口径。生成代码、纯声明和第三方代码可合理排除，但不得排除困难业务代码以提高数字。

合并阶段执行快速单元、组件、契约、静态检查和受影响集成测试；候选发布执行完整回归和必要端到端测试。性能、恢复和安全专项在首次上线、相关架构／依赖／容量变化及登记周期执行；不要求每次文档修改都压测。

## 最小场景集

正常操作；空值、长度与数值边界；未登录；无操作权限；访问其他用户或租户资源；重复请求和超时后重试；并发修改；数据库回滚；外部依赖不可用；分页空页与上限；前端旧请求覆盖；大 ID 和金额精度；旧版本兼容；迁移失败与发布回滚。某场景不适用时说明理由。

## 缺陷与验收

| 等级 | 定义 | 交付条件 |
| --- | --- | --- |
| P0 | 数据损坏、大范围中断、严重安全影响 | 立即处置，阻止发布 |
| P1 | 关键业务失败或结果错误，缺少可接受绕行 | 修复并回归后发布 |
| P2 | 非关键功能异常或存在可接受绕行 | 明确影响、业务确认和修复期限 |
| P3 | 低影响体验、文案或非关键优化 | 登记后纳入迭代 |

P0／P1 不得以口头接受替代处理。误报须有复核证据；业务确认风险接受仍须满足安全底线和有效例外要求。测试报告记录版本／制品摘要、环境、通过失败数量、未执行项、缺陷和明确“通过／有条件通过／不通过”；有条件通过列明条件及完成证据。
