## 日常开发的关键边界

- 模块通过公开接口协作，不跨模块访问内部实现或直接写其他模块数据；分清接入、编排、领域与基础设施职责，接口模型与持久化实体隔离（`ARC-003`、`ARC-004`）。
- 后端逐次验证身份、操作权限和资源范围。租户及数据范围来自可信上下文；前端隐藏按钮和客户端传入身份不能替代授权（`ARC-008`、`SEC-002`、`VUE-007`）。
- 业务 ID、金额以字符串传输，Java 金额从十进制字符串构造 `BigDecimal`；明确精度、舍入与时区，禁止将业务 ID 转为 JavaScript 数字（`JAVA-008`、`API-005`）。
- 普通 JSON 响应包含 `code`、`message`、`data`、`traceId`，成功码为字符串 `"0"`，HTTP 状态表达真实结果；204、文件和流按正文处理。分页、错误码与幂等完整默认值按固定规范及合法项目调整执行（`API-003`～`API-006`、`API-008`）。
- 写操作明确事务、幂等、并发冲突与失败恢复；业务唯一性依赖约束或等效强一致机制；查询值参数化，排序白名单，读写有界（`JAVA-009`、`API-006`、`API-009`、`DATA-002`～`DATA-005`）。
- Vue 状态归属明确，清理生命周期资源，提供加载、空数据、失败和重试状态，处理旧请求覆盖；保持键盘、表单标签与可感知错误（`VUE-003`、`VUE-004`、`VUE-006`、`VUE-009`）。
- 生产秘密不得进入仓库、镜像、前端包或日志；不得故意关闭必要授权，已确认可利用且无有效缓解的高危问题不能通过例外放行（`SEC-005`、`SEC-009`、`GOV-004`）。
- 固定工具和依赖版本，按不可变摘要发布；数据迁移受控执行，应用回滚不等于数据回滚，备份必须通过恢复演练验证（`REL-001`、`REL-004`、`REL-007`、`OPS-005`、`OPS-006`）。

## 验证与交付

- 按影响范围执行上表的实际检查；关键金额、状态、权限、幂等、并发有自动化测试，缺陷修复补有效回归。测试数据隔离脱敏，不写生产业务数据（`TEST-001`～`TEST-005`）。
- 必需检查失败阻断，跳过写明原因、期限和替代验证。覆盖率按已登记门槛执行，行 80%、分支 70% 只是推荐起点（`TEST-006`、`TEST-007`）。
- 同步受影响的契约、配置、设计、迁移和运维说明；纯文档变更检查编码、链接、围栏、表格、规则及默认值，不执行无关业务压测（`DEV-005`）。
- 交付说明包含修改文件、行为变化、实际执行的命令与结果、失败及未执行项、已知风险。自查和静态检查不等于上线、验收或独立审批（`DEV-002`～`DEV-004`）。
- 例外使用 `{{standard_dir}}/templates/15-exception.md`，由有职责的人员批准。智能体可以整理证据与草稿，不能代签例外、非作者评审或业务验收（`GOV-003`、`GOV-004`）。
