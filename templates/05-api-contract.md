# 接口契约模板

对应规则：API-001～API-009、SEC-002、TEST-003。

填写说明：本模板用于评审摘要；OpenAPI 文件是机器可读契约，字段、示例与实现须一致。可参考[订单 OpenAPI](../examples/order/openapi.yaml)。

## 接口信息

- 名称、需求号、负责人、评审人：待填写。
- 方法与路径：例如 `POST /api/v1/orders`。
- 契约文件与 operationId：待填写。
- 使用方、版本、是否公开、流量预期：待填写。
- 认证方式、操作权限、资源范围与审计：待填写。

## 输入与输出

| 位置／字段 | 类型与格式 | 必需 | 约束／默认值 | 示例 |
| --- | --- | --- | --- | --- |
| Header / Idempotency-Key | string | 是 | 8～128 位允许字符 | order-create-demo-001 |
| Body / productId | string | 是 | 业务 ID | 9007199254740995 |
| Body / quantity | integer | 是 | 1～100 | 2 |

- 成功状态、响应模型和示例：待填写，使用 `code/message/data/traceId`。
- ID、金额、币种、时间和空值语义：待填写。
- 分页、筛选、排序白名单与上限：待填写或不适用。
- 文件／流／204 等例外：待填写或不适用。

| HTTP 状态 | 业务码 | 触发条件 | 客户端行为 | 测试用例 |
| --- | --- | --- | --- | --- |
| 400 | COMMON.VALIDATION_FAILED | 参数非法 | 提示字段错误，不自动重试 | 待填写 |
| 409 | COMMON.IDEMPOTENCY_CONFLICT | 同键不同业务载荷 | 提示冲突，不覆盖原意图 | 待填写 |
| 503 | COMMON.SERVICE_UNAVAILABLE | 依赖不可用 | 按契约安全重试或查询结果 | 待填写 |

## 副作用与失败处理

- 事务、状态变化、并发更新控制：待填写。
- 幂等键范围、指纹字段、保留期、原子性、重放结果、处理中行为：待填写。
- 超时、限流、重试预算、结果未知与过期键处理：待填写。
- 响应及日志敏感信息：待填写。

## 兼容与验收

- 对已有使用方的影响、迁移窗口、废弃日期：待填写。
- 契约测试与正反例位置：待填写。
- 评审结论、未决项和关闭证据：待填写。
