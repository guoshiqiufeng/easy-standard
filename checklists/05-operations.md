# 日常运维与周期检查清单

[返回首页](../README.md) · 产物：[运维手册](../templates/12-runbook.md)、[恢复演练](../templates/13-recovery-drill.md)、[复盘](../templates/14-incident-review.md)。

服务／环境／检查周期／执行人：待填写。下面频率是推荐起点，项目在基线登记实际频率及责任人。

每行记录日期、通过／不通过／不适用、证据及跟踪项；发现影响业务的异常进入事件流程，不能只勾选“已检查”。

| 建议时机 | 检查内容 | 规则 | 实际记录／责任人 |
| --- | --- | --- | --- |
| 每日 | 业务成功率、错误、时延和关键告警 | OPS-002、OPS-003 | 待填写 |
| 每日 | 备份结果、新鲜度、持久化卷与磁盘容量 | OPS-005、OPS-007 | 待填写 |
| 每周 | 容量趋势、资源饱和、队列、证书和异常日志 | OPS-007 | 待填写 |
| 每周 | 漏洞、依赖维护和需升级制品 | SEC-009、OPS-007 | 待填写 |
| 每月 | 告警通知通路、值守安排、故障操作说明有效性 | OPS-001、OPS-003 | 待填写 |
| 每月 | 生产账号、最小权限、密钥轮换和审计访问 | SEC-005、SEC-008、OPS-010 | 待填写 |
| 每月 | 数据保留、归档、删除、缓存容量和批处理核对 | DATA-006、DATA-007、DATA-008、DATA-009 | 待填写 |
| 每月 | 例外到期、存量整改与故障改进闭环 | GOV-004、GOV-006、OPS-009 | 待填写 |
| 首次上线／重大变化／登记周期 | 恢复演练、实际 RPO／RTO和业务核验 | OPS-006 | 待填写 |
| 重大变化后 | 实例退出、依赖故障、流量就绪与恢复行为 | OPS-004 | 待填写 |
| 事件发生时 | 分级、响应、证据、恢复和沟通 | OPS-008、SEC-011 | 待填写 |

| 每季度 | 规范版本与来源复核、规则变更和迁移计划 | GOV-005 | 待填写 |
| 退役时 | 依赖迁移、数据处置、秘密撤销、资源释放与验收 | GOV-007、OPS-011 | 待填写 |

异常与后续行动：事项、影响、责任人、截止时间、验证方式，待填写。
