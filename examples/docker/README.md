# Docker Compose 配置示例

[返回首页](../../README.md) · 对应规则：REL-002、REL-004～REL-008、SEC-005、SEC-006、OPS-004、OPS-005。

这是服务部署配置样例，不包含镜像构建或实际数据库。它保留技术栈中立，不假定 Spring、某数据库或 Web 服务器；需要项目提供符合下述契约的镜像。占位镜像不能拉取，也不能直接上线。

## 文件与使用边界

- [compose.yaml](compose.yaml)：Java API 和 Vue 静态站点容器，提供资源限制、健康检查、只读根文件系统、非 root、日志轮转和退出宽限。
- [.env.example](.env.example)：公开变量名称与无效占位值；只允许登记数据库地址，不嵌入密码。
- 数据库／文件服务由项目另行选择与部署，独立登记连接、身份、备份和恢复。api-data 卷只示例应用持久化路径，无此需求时应移除并更新部署设计。

本例用于 Linux Docker Engine 和兼容的 Compose 插件。采纳时登记实际版本，先验证 `docker compose config`，再在预生产验证运行时行为。内存与 CPU 数值是示例容量，需要负载测试确定；Java 堆、直接内存、线程栈和运行时开销合计须低于容器限制。

## 镜像与入口必须满足的契约

| 项目 | 必须实现或验证 |
| --- | --- |
| 镜像来源 | 已审批仓库的 `name@sha256:...` 固定摘要，扫描通过；Compose 只检查变量存在，部署检查另验证摘要和来源 |
| 身份与端口 | UID／GID 10001 可启动，监听容器 8080，不需要 root 或额外能力 |
| 健康脚本 | 镜像内提供可执行 `/app/bin/healthcheck`，参数 ready／live；成功退出 0，失败非 0，5 秒内结束，不依赖未安装 curl 或 shell |
| API 配置 | 应用明确读取 APP_DB_URL，以及两个 `_FILE` 指向文件中的数据库身份；这些是本例约定，不是所有框架的自动功能 |
| 秘密访问 | 宿主机受控文件已存在；容器用户能读取，其他不必要主体不能访问；实际检查文件权限与运行环境行为 |
| 写目录 | 只写允许的 `/tmp` 和 `/app/data`；镜像预置正确目录权限，并验证新卷与已有卷所有权 |
| Web 静态服务 | 服务端和临时缓存可在只读根文件系统＋`/tmp` 下工作；静态资源与前端路由回退已配置 |
| 退出 | 接收 SIGTERM，停止接新请求并完成或安全回滚在途任务；API 在 45 秒内退出 |
| 日志 | 输出标准输出／错误，敏感字段脱敏，不将日志无限写入持久化卷 |

## 网络与秘密

两个端口只绑定宿主机 127.0.0.1，由项目已有的宿主机反向代理提供 HTTPS 和同源路由：`/api/` 转发 18080，其余转发 18081，保留 API 前缀。代理需正确设置大小、超时、可信转发头和访问日志策略。若代理本身运行在容器中，必须单独设计容器网络与地址，不能假设该容器的 localhost 就是宿主机。

数据库和管理接口不在本配置对公网发布。健康端点只向受控网络或本地健康脚本开放。Compose 本地文件 secrets 不是托管加密密钥服务；文件的存放、权限、轮换和备份由运维方案负责。文件内容末尾换行的处理由应用配置加载明确规定。

`restart: unless-stopped` 处理进程退出，并不会因为 healthcheck 为 unhealthy 就自动重启；需要监控、外部探测和已审查的恢复流程。Compose 不提供跨主机故障转移，也不自动保证更新零停机。

## 配置检查与演练

只做配置解析的示例命令，不启动或下载任何服务：

```sh
docker compose --env-file .env.example -f compose.yaml config --quiet
```

该检查至多确认 Compose 配置结构和变量替换；不能证明占位镜像可运行、秘密文件可读、数据库可连、摘要可信或应用支持这些变量。正式运行前执行以下验证并保存证据：

1. 替换真实镜像摘要和数据库引用，核对秘密文件可读性，验证镜像不包含密钥。
2. 验证非 root、只读根、卷权限、内存限制和健康脚本；校验 API 前缀、前端路由刷新、HTTPS 与授权。
3. 模拟依赖失败、实例退出和重启，确认错误、恢复、就绪与日志轮转。
4. 备份持久化数据到独立故障域，在隔离环境恢复并核对；容器卷不是备份。
5. 按维护窗口或经验证的切流方案更新同一制品，演练旧镜像与对应配置恢复。

在正式项目中复制使用时，可将 `.env`、秘密文件及临时运行产物加入项目忽略配置，但秘密的首要防线仍是受控存储、最小权限和扫描。
